# Release 2.0.9

Version 2.0.9 liefert einen Mobile-UX-Fix fuer das Chat-Overlay mit Fokus auf kleine und querformatige Viewports.

## Highlights

- Mobile Overlay auf Fullscreen-Darstellung vereinheitlicht
- In kleinen Viewports nur noch Schließen (`X`) statt Minimize/Maximize-Umschaltung
- Landscape-Fix: keine Ueberlagerung mehr zwischen Datenschutzhinweis, Eingabefeld und Senden-Button
- Kompakter Flyout-Toggle fuer Kanaele (`>>` / `<<`)

## Kompatibilitaet

- Plugin-Version: `2.0.9`
- Getestet bis WordPress `6.9`
- Keine Migration erforderlich
