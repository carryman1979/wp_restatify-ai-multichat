# Release 2.0.7

Version 2.0.7 konsolidiert den unveroeffentlichten lokalen Entwicklungsstand seit 2.0.6 in einen finalen Release-Kandidaten.

## Highlights

- Plugin-Version auf `2.0.7` angehoben
- Unveroeffentlichte lokale Release-ZIPs oberhalb `2.0.6` bereinigt
- Session-1/Session-2-Flow inkl. deterministischem Routing und Prefill-Pfad in den Release-Dokumenten finalisiert
- Admin-Einstellungsstruktur und begleitende Doku auf konsistenten Final-Stand gebracht
- Testbasis auf Gated-Checkin-Stand verifiziert

## Kompatibilitaet

- Plugin-Version: `2.0.7`
- Getestet bis WordPress `6.9`
- Keine Migration erforderlich
