# Restatify Multi Chat Overlay 2.0.0

## Was ist neu

- Plugin-Slug auf `wp_restatify-ai-multichat` vereinheitlicht
- Interne Runtime in drei Klassen getrennt (`Options`, `Chat`, `Admin`)
- Admin- und Overlay-Markup in Templates ausgelagert
- Version auf `2.0.0` angehoben

## Warum

Das Release reduziert Komplexitaet im Runtime-Code und verbessert Wartbarkeit, Fehlersuche und Erweiterbarkeit fuer kommende Features.

## Kompatibilitaet

- Plugin-Version: `2.0.0`
- WordPress getestet bis `6.9`
- Keine manuellen Migrationsschritte fuer Einstellungen erforderlich
