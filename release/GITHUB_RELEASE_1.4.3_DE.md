# Restatify Multi Chat Overlay 1.4.3

## Was ist neu

- LightStart-Wartungsmodus-Integration hinzugefuegt
- Neue Einstellung: `Bei LightStart-Wartung ausblenden` (Standard: aktiviert)
- Einstellung nur sichtbar, wenn LightStart installiert und aktiv ist
- Overlay wird bei aktivem Wartungsmodus optional unterdrueckt

## Hintergrund

Im Wartungsbetrieb soll die Seite bei Bedarf ohne Chat-Overlay dargestellt werden. Die neue Einstellung ermoeglicht dieses Verhalten ohne manuelle Plugin-Deaktivierung.

## Kompatibilitaet

- Keine Breaking Changes in bestehenden Optionen
- Single-Site und Multisite-Netzwerkaktivierung werden unterstuetzt
