# Restatify Multi Chat Overlay 2.0.5

## Was ist neu

- WordPress-Einstellungsmenue auf `AI Multichat` umbenannt
- Ueberschrift der Einstellungsseite auf `AI Multichat` umgestellt

## Warum

Damit entspricht die Admin-Bezeichnung dem aktuellen Plugin-Namen und vermeidet Verwechslungen mit dem Legacy-Namen.

## Kompatibilitaet

- Plugin-Version: `2.0.5`
- WordPress getestet bis `6.9`
- Keine Datenmigration erforderlich
