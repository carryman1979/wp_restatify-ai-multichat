# Restatify AI Multichat 2.0.9

## What's new

- Unified mobile chat overlay behavior to full-screen mode on small viewports.
- Simplified mobile interaction: close-only (`X`) in small viewports instead of minimize/maximize switching.
- Fixed landscape layout overlap so legal notice, input field, and send button remain visible and usable.
- Switched channel flyout toggle in landscape to compact arrows (`>>` / `<<`).

## Compatibility

- Plugin version: `2.0.9`
- Tested up to WordPress `6.9`
- No migration required.
