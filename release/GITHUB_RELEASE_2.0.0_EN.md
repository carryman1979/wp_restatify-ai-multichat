# Restatify Multi Chat Overlay 2.0.0

## What's new

- Standardized plugin slug to `wp_restatify-ai-multichat`
- Split runtime into three focused classes (`Options`, `Chat`, `Admin`)
- Moved admin and overlay markup into dedicated templates
- Bumped plugin version to `2.0.0`

## Why

This release reduces runtime complexity and improves maintainability, debugging, and future extensibility.

## Compatibility

- Plugin version: `2.0.0`
- Tested up to WordPress `6.9`
- No manual option migration required

- `wp_restatify-ai-multichat-2.0.0.zip`
