# Restatify AI Multichat 2.0.9

## Neu in diesem Release

- Mobile Darstellung des Chat-Overlays auf Fullscreen-Verhalten vereinheitlicht.
- Mobile Bedienung vereinfacht: in kleinen Viewports nur noch Schließen (`X`) statt Wechsel zwischen minimiert/maximiert.
- Layout-Fix fuer Landscape: Datenschutzhinweis, Eingabefeld und Senden-Button ueberlagern sich nicht mehr.
- Kanal-Flyout-Button in Landscape auf kompakte Pfeile (`>>` / `<<`) umgestellt.

## Kompatibilitaet

- Plugin-Version: `2.0.9`
- Getestet bis WordPress `6.9`
- Keine Migration erforderlich.
